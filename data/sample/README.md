# SAMPLE DATA — PREDIKSI PRESISI

Semua file di folder ini adalah DATA SINTETIS/DUMMY.

Dipakai untuk:
- development UI;
- testing API;
- heatmap/peta;
- risk score;
- prediction;
- early warning;
- recommendation;
- commander approval;
- operational workflow;
- prediction vs actual.

Jangan menganggap dataset ini sebagai kondisi Kamtibmas nyata.

Untuk data resmi gunakan:
`data/raw/ → data/import/ → validation → mapping → anonymization → data/processed/ → database`

Jangan langsung menimpa data dummy.
